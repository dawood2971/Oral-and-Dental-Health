# ابتسامتي صحتي: صفحة توعية تفاعلية بصحة الفم والأسنان

صفحة توعوية تفاعلية لطلاب الصفوف الخامس والسادس والسابع، ضمن برنامج تعزيز صحة الفم والأسنان في المجتمع المدرسي (نوفمبر 2026).

- **الأقسام التفاعلية:** بطاقات العادات السبع، خطوات التفريش مع مؤقّت الدقيقتين، مسابقة «صح أم خطأ؟»، جدول تحدّي 28 يوماً (يُحفظ على الجهاز)، لعبة «المحقّق سنّون» لرائحة الفم، ولعبة ترتيب خطوات إنقاذ السن المخلوع.
- **المكتبة التثقيفية:** لكل موضوع ملصق جداري (PDF)، إنفوجرافيك (PNG/PDF)، فيديو موشن جرافيك (MP4)، وسيناريو الفيديو ولوحة القصة، إضافة إلى دليل الأنشطة والشرائح الإضافية للجلسات.

## النشر
الصفحة ثابتة بالكامل (HTML وCSS وJS بلا أدوات بناء). للنشر: Settings ← Pages ← Deploy from a branch ← `main` / root.
