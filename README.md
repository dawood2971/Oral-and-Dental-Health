# صحة الفم والأسنان: صفحة توعية تفاعلية

صفحة توعوية تفاعلية لطلاب الصفوف الخامس والسادس والسابع، ضمن برنامج تعزيز صحة الفم والأسنان في المجتمع المدرسي (نوفمبر 2026).

الموقع صفحة رئيسية قصيرة وخمس صفحات مستقلة:

| الصفحة | الملف | الجمهور | المحتوى |
|---|---|---|---|
| الرئيسية | `index.html` | الجميع | مدخل للطلاب ومدخل للمعلم والممرض |
| الاختبارات والألعاب | `games.html` | الطلاب | اختبار العناية بالأسنان، واختر الغذاء الصحيح، واصطاد السوسة، والتفريش ومؤقّت الدقيقتين، وصح أم خطأ، والمحقّق سنّون، والإسعاف السريع |
| خريطة الفم والأسئلة | `mouth.html` | الطلاب والأسر | خريطة تفاعلية للأسنان واللثة واللسان، و12 سؤالاً شائعاً |
| التحدي والشهادة | `challenge.html` | الطلاب | جدول تحدّي 28 يوماً يُحفظ على الجهاز، وشهادة «بطل الأسنان النظيفة» |
| المكتبة الرقمية | `library.html` | الجميع | الإنفوجرافيك، و12 فيديو، والملصقات |
| ركن المعلم والممرض | `teachers.html` | المعلم والممرض | قصص للنقاش، وتجربة البيضة والخل، وخطة الأنشطة، وكل الملفات في جدول تحميل واحد |

الخطوط: Times New Roman للعناوين، وIBM Plex Sans Arabic للنص.

مولّدات المواد (الملصقات والإنفوجرافيك والفيديو والصفحة) في مجلد `tools/`.

## الحركة
طبقة الحركة في `assets/motion.js` و`assets/motion.css` (مع `assets/lenis.css`)، ومصدرها في `tools/motion/`:
التمرير الناعم بـ Lenis مربوط بمؤقّت GSAP مع ScrollTrigger، ومكوّنات React Bits (Blur Text للعنوان، وLight Rays لخلفية الواجهة، وStar Border للزر الأساسي، وCount Up للأرقام)، وظهور الأقسام بهدوء عند التمرير.
عند تفعيل «تقليل الحركة» في الجهاز تتوقف كل الحركة وتظهر الصفحة ثابتة.
لإعادة البناء: `cd tools/motion && npm install && npm run build`.

## النشر
الصفحة ثابتة بالكامل (HTML وCSS وJS بلا أدوات بناء). للنشر: Settings ← Pages ← Deploy from a branch ← `main` / root.
