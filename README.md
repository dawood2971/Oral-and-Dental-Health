# ابتسامتي صحتي: صفحة توعية تفاعلية بصحة الفم والأسنان

صفحة توعوية تفاعلية لطلاب الصفوف الخامس والسادس والسابع، ضمن برنامج تعزيز صحة الفم والأسنان في المجتمع المدرسي (نوفمبر 2026).

الصفحة مقسّمة إلى خمسة أقسام:

1. **الاختبارات والألعاب:** اختبار «هل تعتني بأسنانك بالطريقة الصحيحة؟» مع تقييم فوري، ولعبة «اختر الغذاء الصحيح للسن»، ولعبة «اصطاد السوسة»، وخطوات التفريش مع مؤقّت الدقيقتين بالموسيقى والرسوم المتحركة، ومسابقة «صح أم خطأ؟»، ولعبتا المطابقة وترتيب خطوات إنقاذ السن.
2. **المكتبة الرقمية:** معرض الإنفوجرافيك (تنزيل ومشاركة)، واستوديو الفيديو (11 فيديو موشن جرافيك، منها 9 مع سيناريوهاتها)، وركن الملصقات الجدارية الجاهزة للطباعة.
3. **دليل الجلسات والورش:** حقيبة الطالب (قصص قصيرة، وتجربة البيضة والخل، وأسئلة للنقاش)، ودليل المعلم والممرض (عروض الجلسات الخمس، والأدلة، والشرائح الإضافية).
4. **خريطة الفم والأسئلة الشائعة:** خريطة تفاعلية للأسنان واللثة واللسان، و12 سؤالاً شائعاً بإجابات مبسّطة.
5. **التحديات وحساب العادات:** جدول تحدّي 28 يوماً يُحفظ على الجهاز، وشهادة «بطل الأسنان النظيفة» للتنزيل والطباعة.

مولّدات المواد (الملصقات والإنفوجرافيك والفيديو والصفحة) في مجلد `tools/`.

## النشر
الصفحة ثابتة بالكامل (HTML وCSS وJS بلا أدوات بناء). للنشر: Settings ← Pages ← Deploy from a branch ← `main` / root.
